# 🌵 Cacto Dançante 3D

Simulador 3D de um cacto dançante de pelúcia, feito com HTML + [three.js](https://threejs.org/) (r128).

## Recursos
- Cacto 3D em cima de uma mesa, com vaso de pelúcia e corpo de tricô
- 4 músicas (Parabéns, Brilha Brilha, Ode à Alegria, Sinos) sintetizadas com Web Audio
- **Modo eco**: escuta sua voz pelo microfone e repete com tom agudo, dançando
- Campo de texto: o cacto fala o que você digitar (Web Speech API)
- Câmera orbital: arraste para girar, role para dar zoom

## Como usar
Abra o `index.html` no navegador. Para o microfone funcionar, sirva por HTTPS ou `localhost`:

```bash
python3 -m http.server 8000
```

Depois acesse http://localhost:8000.
